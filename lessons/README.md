# Lessons

Student-facing notebooks from the 2022 course. Links below open readable text previews; each preview links to its editable `.Rmd` source. No R code was executed to create the previews. Many code blanks are intentional live-coding or student tasks.

- **[Module 2: Summarizing data](mod2/mod2_students.md)** — structure, indexing, summaries, grouped comparisons, and long versus wide data.
- **Module 3:** [independent data exploration](mod3/mod3_day1_student.md) and [scatterplots and bivariate relationships](mod3/mod3_day2_student.md).
- **[Module 4: Distributions and correlation](mod4/mod4_student.md)** — air quality, boxplots, missing observations, and counts versus proportions.
- **[Module 5: Visualizing flow data](mod5/mod5_lecture_students.md)** — flight destinations, alluvial plots, and clear grouping choices.
- **[Module 6: Missing and messy data](mod6/mod6_missing_data_student.md)** — inspecting missingness in `airquality`, comparing patterns, and discussing implications.
- **[Module 10: Text as data](mod10/day2-live-coding-student.md)** — Colin Henry's guided text-analysis notebook. Read the [context and data notes](mod10/README.md).
- **[Module 11: Mapping sea surface temperature anomalies](mod11/mapping-ssta.md)** — NetCDF, spatial grids, NOAA data, and raster maps.
- **[Module 12: Spatial data](mod12/mod12_spatial_student.md)** — polygon maps, joins, demographic overlays, and historical web-mapping examples.
- **[Module 13: K-means](mod13/mod13_student.md)** — scaling, distance, cluster interpretation, and comparison across choices of k.

The original module sequence is incomplete in the public archive. Instructor-only versions are not released. For a topic map including assessments and homework, see the [reconstructed syllabus](../SYLLABUS.md).

**Before running code:** consult [data and reuse](../docs/DATA_AND_REUSE.md). Some inputs are withheld, external services may have changed, and the spatial lessons can make network requests or install packages. No credentials are needed to read these pages.
