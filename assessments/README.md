# Assessment examples

Student-facing historical prompts without solutions, student submissions, or grade records. Their dates, time limits, point values, and collaboration rules describe the original classroom context.

- **[Module 5 exploratory challenge](mod5/mod5_quickfire.md)** — produce and interpret two different visualizations of state-level health and political data. Its [data dictionary](mod5/data_dictionary.md) is retained; the underlying CSV is not redistributed.
- **[Module 8 midterm](mod8-midterm/midterm_students.md)** — describe unfamiliar data, assess missingness, summarize distributions, and ask and answer exploratory questions. Its four sections allocate 20, 20, 40, and 20 points. Local datasets and the associated data PDF are not redistributed.
- **[Module 15 exploratory challenge](mod15/quickfire2.md)** — create a presentation-quality graphic and attempt another analysis using clustering, text sentiment, or mapping. Its election and tweet datasets are not redistributed.

In the module 15 source, the third dataset is named incorrectly in the list, and the code uses filename capitalization that differs from the original files. Those historical inconsistencies are not evidence that an input exists in this public edition. See [data and reuse](../docs/DATA_AND_REUSE.md).

The [final-project guide](../project-template/README.md) shows how a longer exploratory analysis was organized for reproducibility and communication.
