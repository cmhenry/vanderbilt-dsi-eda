# Assignments

Historical prompts, not current deadlines. Student names and due-date placeholders in templates are not completed submissions. Readable companions show source text and code without executing it.

- **[Module 1: R Markdown](mod1/week1_hw.md)** — knit source to readable formats and use the course's GitHub submission workflow.
- **[Module 2: Summaries and UCB admissions](mod2/mod2_hw.md)** — describe structure, make grouped summaries, and propose another relationship to examine. Section 1 refers to lecture notes not released as an instructor key; Section 2 uses package data.
- **[Module 3: NOAA storm events](mod3/mod3_hw.md)** — compare storm deaths, injuries, and damage costs; question potentially misleading graphics; develop another exploratory question.
- **[Module 4: Elections and wine quality](mod4/mod4_hw.md)** — investigate distributions, compare variables, and explore a correlation matrix. Only the separately attributed red-wine CSV is bundled; the election data are not.
- **[Module 5: Independent data report](mod5/mod5_hw.md)** — explain data provenance, formulate a question, select two final graphics, and reflect on data preparation. The class signup sheet is replaced by a public-edition note.
- **[Module 6: Missingness](mod6/mod6_hw.md)** — use evidence to discuss MCAR, MAR, and MNAR in an instructional workout-study scenario. Its local data are withheld; observed patterns alone do not prove a mechanism.
- **[Module 10: Text as data](mod10/hw-10.md)** — tokenization, word counts, TF-IDF, sentiment, and interpretation. The original corpora are not bundled.
- **[Module 12: Time-series data](mod12/mod12-hw-time-series.md)** — line plots, country comparisons, time-series objects, autocorrelation, and decomposition.
- **[Module 13: K-means](mod13/mod13_hw.md)** — prepare country-level variables, choose k, examine the clusters, and improve their graphical presentation. The local COVID dataset is not bundled.
- **[Module 15: Messy class survey](mod15/mod15-hw.md)** — clean variable names and types, investigate measurement challenges, and interpret two distinct graphics. Survey responses and the live form link are withheld.

Editable `.Rmd` sources accompany the previews where the original prompt was R Markdown. See [data and dependencies](../docs/DATA_AND_REUSE.md) and the [final-project guide](../project-template/README.md).
