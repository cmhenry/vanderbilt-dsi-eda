# Final project: from exploration to a reproducible report

Adapted from the instructor-provided `EDA-project-ex` organizational example by Cassy Dorff. This is a **project template, not a completed student project**.

The original guidance asks students to organize their exploratory work, make the main findings reproducible, and communicate results through a final written report and presentation. Each team should explain its own question, data, file structure, and key files in a project-specific README.

## Recommended structure

```text
project/
├── README.md
├── 1_preprocessing/
├── 2_data/
│   ├── data_raw/
│   └── data_clean/
├── 3_main_findings/
├── 4_deliverables/
└── meeting_notes.md
```

- **[1_preprocessing](1_preprocessing/README.md):** organized, annotated code for inspection, cleaning, wrangling, joins, and exploratory analyses that motivate the final work.
- **[2_data](2_data/README.md):** separate original inputs from the final cleaned data used in the report. Record provenance and respect access and redistribution restrictions.
- **[3_main_findings](3_main_findings/README.md):** a clear execution path that reproduces every reported finding and figure from the cleaned data, with brief annotations.
- **[4_deliverables](4_deliverables/README.md):** final report and presentation slides. Use high-quality graphics and tables, not rough screenshots.
- **[meeting_notes.md](meeting_notes.md):** concise coordination notes in reverse chronological order, including decisions and responsibilities.

## Project progression

1. Select a question and candidate datasets; obtain instructor approval.
2. Inspect, clean, and explore the data, documenting analytical choices.
3. Develop the report and reproducible main-findings code together.
4. Prepare and rehearse the presentation.
5. Revise the report and submit the final deliverables.

These stages summarize the original example. No new deadlines, grade weights, team sizes, or report-length requirements are invented. The original course asked students to keep **their project repositories private**. This public instructor-materials collection does not change that instruction or authorize publication of data or student work.

The original example's placeholder spreadsheets and sample PDF are not included. The folder notes and meeting-note fields below are newly written scaffolds, not evidence of completed analyses or real meetings.
